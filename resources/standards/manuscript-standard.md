# Manuscript standard

- **Title**: states the finding or the object and setting, not just the method name.
- **Abstract**: problem, approach, main quantitative result with the split it comes from, main limitation, implication.
- **Introduction**: gap → closest prior work → specific contribution. Ends with the contribution, not a roadmap.
- **Methods**: enough to repeat; deviations from protocol disclosed; data, code and AI-use statements.
- **Results**: primary outcome first; uncertainty for every headline number; tables and figures referenced in order.
- **Discussion**: what the results mean within their scope; comparison with prior work; limitations specific to this study; hypotheses labelled as such.
- **Conclusion**: no claim that is not in the results.
- **Notation**: one symbol, one meaning; terms defined at first use.
